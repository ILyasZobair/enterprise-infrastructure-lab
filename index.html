Présentation du projet

Ce projet est un laboratoire pédagogique consacré à l'administration des réseaux et des systèmes informatiques. Il présente une architecture réseau segmentée en VLAN, des scripts PowerShell pour Windows Server et des scripts Bash pour l'administration Linux.

Domaines techniques

Réseaux Cisco

Configuration des VLAN, ports Access, trunk 802.1Q, routage inter-VLAN et tests de connectivité.

Windows Server

Administration système avec PowerShell, inventaire matériel et exemples de gestion des utilisateurs Active Directory.

Linux Server

Ubuntu Server, installation de Nginx, SSH, gestion des services et sauvegardes automatisées avec Bash.

Objectifs pédagogiques

  • Comprendre la segmentation réseau.
  • Documenter une infrastructure informatique.
  • Découvrir l'administration Windows Server.
  • Automatiser des tâches avec PowerShell et Bash.
  • Apprendre à tester et dépanner des services réseau.
