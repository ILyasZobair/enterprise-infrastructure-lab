Présentation du projet

Bienvenue dans mon laboratoire informatique. Ce projet présente une infrastructure pédagogique dédiée à la configuration des réseaux, à l'administration de Windows Server et à Linux.

L'objectif est de développer des compétences pratiques en administration système, en réseau et en automatisation.

Domaines techniques

Réseaux Cisco

Configuration des VLAN, des ports Access, des liens trunk 802.1Q et du routage inter-VLAN.

show vlan brief

show interfaces trunk

Windows Server

Administration avec PowerShell, inventaire système et gestion des utilisateurs avec Active Directory.

Get-ComputerInfo

Get-NetIPConfiguration

Linux Server

Administration Ubuntu Server, installation de services, gestion de SSH et Nginx, et réalisation de sauvegardes.

ip -br address

systemctl status nginx

Plan d'adressage IP

Exemple de segmentation réseau pour le laboratoire.

VLAN Service Réseau Passerelle
10 Administration 192.168.10.0/24 192.168.10.1
20 Employés 192.168.20.0/24 192.168.20.1
30 Serveurs 192.168.30.0/24 192.168.30.1

Serveurs du laboratoire

Windows Server

Adresse IP : 192.168.30.10

Rôle : administration système et services d'annuaire si configurés.

Linux Server

Adresse IP : 192.168.30.20

Rôle : services Linux, SSH, serveur Web Nginx et sauvegardes.

Tests et vérifications

Tests réseau

show ip interface brief

show vlan brief

ping 192.168.30.20

Tests Windows

ipconfig /all

Get-ComputerInfo

Test-NetConnection 192.168.30.20

Tests Linux

ip -br address

systemctl status ssh

curl http://localhost

Objectifs pédagogiques

  • Comprendre les VLAN et le routage inter-VLAN.
  • Créer un plan d'adressage IP.
  • Découvrir l'administration Windows Server.
  • Automatiser des tâches avec PowerShell.
  • Administrer les services Linux avec Bash.
  • Documenter et tester une infrastructure.
